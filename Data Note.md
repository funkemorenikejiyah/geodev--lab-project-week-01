## Number of Features
774

## The key columns 
the key columns are: 
Admin2 name which shows the names of LGAs
Admin 2 pcode showing point code
Admin 1_name showing state name
Area in sq km
Latitude and Longitude columns showing location
Date

## Geometry Type
Polygon

## Gap or Missing Values
Date only shows downloaded date but does not contain expiry date.
All admin2_1,2,3 columns which represent the local goverments have null values, likewise the coumns for Admin1_name1,2,3 and Admin0_1,2,3.
Other columns with null values are valid to date and lang1,2,3.
